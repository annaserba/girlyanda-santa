# Карта организатора

На главной используется только обезличенный агрегат. Маршрут `/garland`
доступен администраторам: до чтения персональных данных проверяется роль,
а отдельный серверный загрузчик повторяет проверку. Публикация общей карты
не открывает доступ к этой странице обычным участникам или гостям.

Задача — найти участников по городам и проверить получателей и состояние подарков.
Один экземпляр существующей SVG-карты России, прежняя проекция и геоданные.
Геометрия и подписи формируются сервером. Гирлянда остаётся декоративной;
фактические пары указаны в списке участников под картой.

До жеребьёвки показаны подтверждённые анкеты; после неё — участники последней
завершённой гирлянды. Снимок данных читается в одной транзакции repeatable read.
Передаются ФИО, город, площадка, смена, трек, идентификаторы пар и состояния подарков.
Телефоны, почта, ПВЗ и токены раскрытия в этот экран не загружаются.

React управляет выбором города, поиском по ФИО/площадке и страницей списка.
Нажатие на город показывает его участников. Тот же выбор доступен через
обычный список городов, поэтому он работает и без наведения мыши.
Поиск не записывает ФИО в URL, localStorage или историю браузера; состояние
сбрасывается при новом открытии страницы. Данные обновляются при открытии
или ручной перезагрузке, фоновых запросов нет.

На широком экране карточки в две колонки, на телефоне — в одну, под картой.
На странице не более 50 карточек; поиск работает по всему снимку до 1500 человек.
Клиент получает готовый SVG, без D3/геоданных и без новой карты или внешних тайлов.
Без JavaScript остаются SVG, первые 50 карточек и ссылки на текстовый блок.
Города без координат доступны через список и поиск.

Основной локальный проход — geospatial, поддержка — React/Next.js.
Проверки: запрет загрузки для гостей/участников/координаторов, доступ администратора
при любом флаге публикации, отсутствие персональных полей на главной,
сохранение реальных пар и статусов, поиск и SSR списка. Ручная проверка браузера
на desktop и телефоне остаётся отдельной приёмкой, см. `docs/verification.md`.
