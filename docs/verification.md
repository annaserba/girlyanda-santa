# Проверки

Используйте Node.js 22 и зависимости из `package-lock.json`.

- `npm run typecheck`: TypeScript.
- `npm test`: алгоритмы колец, запреты пар, анкеты, права, обработчики API,
  импорт, телефон и города, SSR интерфейса, геометрия карты, анимация и CI/CD.
- `npm run test:db`: жизненный цикл с реальными миграциями и PostgreSQL,
  только в отдельной базе `santa_verification`.
- `npm run build`: production-сборка Next.js.

Перед публикацией выполнены проверка типов, 314 unit/SSR-тестов,
16 интеграционных тестов в изолированной PostgreSQL и production-сборка.
Результаты автоматических проверок не заменяют визуальную приёмку.

## Ручная приёмка

Проверка в браузере остаётся необходимой и не заявлена как выполненная.
Проверьте главную, регистрацию, вход, личный кабинет, организатора и координатора
на широком экране, телефоне и в альбомной ориентации.

Проверьте поиск и выбор города мышью и клавиатурой, фокус и сообщения об ошибках,
ввод телефона РФ, порядок полей и необязательность площадки.
На карте проверьте плавность кольца, читаемость подписей, анимацию при загрузке
и ручную паузу. Персональные сведения не должны появляться на публичной карте.

Перед рассылкой проверьте ссылку на кабинет из внутренней сети и лимит BCC
вашего почтового клиента. Перед включением CD проверьте доступы платформы
и раскрытый GitLab pipeline в целевом контуре.
