# Секреты и персональные данные

Репозиторий содержит исходный код и общедоступные справочники.
Реальные адреса участников и администраторов, пароли, токены, базы,
резервные копии и рабочие `.env` не должны попадать в Git.

`.env.example` содержит пустые поля для секретов. Генерируйте собственные значения.
Локальные настройки и заметки игнорируются Git и Docker context.
Секреты развёртывания передавайте через настройки окружения или Vault.

Не используйте действующие адреса и пароли в тестах, примерах, issue,
скриншотах, логах сборки и описаниях коммитов. Тестовые адреса в проекте
используют зарезервированные домены; контактные данные поставщиков в их
лицензиях и метаданных сохранены.

Подтверждение почты отключено. Администратора регистрируют до открытия сервиса:
первый аккаунт автоматически становится администратором.
Совпадение телефона или почты с импортированной записью не подтверждает личность
и не должно давать доступ к чужому результату.

При обнаружении опубликованного секрета сначала отзовите его, затем очищайте
историю и связанные артефакты. Удаление файла из последнего коммита не удаляет
его из предыдущих ревизий.
